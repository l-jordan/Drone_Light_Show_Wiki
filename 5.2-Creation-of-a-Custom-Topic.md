# Creation of a Custom Topic

The proposed light function required each of the drones to know parameters such as who 

1. Create a new package in ros2_ws/src. In this example it is called offboard_control_interfaces.

2. Create a folder called msg where your topic messages are stored. 

````bash
cd src/offboard_control_interfaces
mkdir msg
```

3. Create a message file called <filename>.msg and write your topic elements in it. We want to use it as an intermediate step between the control node and the drones onboard functionality, thus we included which drone it was following, the follower number it was, the corresponding light colour and the drone's name.

```bash 
string follower_of
int32 follower_number 
string light_colour
string drone_name
```

4. Create a CMakeLists.txt file as seen below.

```python
cmake_minimum_required(VERSION 3.8)
project(offboard_control_interfaces)

if(CMAKE_COMPILER_IS_GNUCXX OR CMAKE_CXX_COMPILER_ID MATCHES "Clang")
  add_compile_options(-Wall -Wextra -Wpedantic)
endif()

find_package(ament_cmake REQUIRED)
find_package(rosidl_default_generators REQUIRED)
find_package(builtin_interfaces REQUIRED)
find_package(std_msgs REQUIRED)

rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/Drone1Info.msg"
  "msg/Drone2Info.msg"
  "msg/Drone3Info.msg"
  DEPENDENCIES builtin_interfaces std_msgs
)
ament_export_dependencies(rosidl_default_runtime)

ament_package()
```

Alter the following components to add your package and custom topics:
```python
project(offboard_control_interfaces) # Change the package name

...

# Add the topics in parentheses in the `rosidl_generate_interfaces`

  DEPENDENCIES builtin_interfaces std_msgs

``` 

5. Alter your package.xml file, ensuring that you have the `ament_cmake` build type

```python
<?xml version="1.0"?>
<package format="3">
  <name>offboard_control_interfaces</name>
  <version>0.0.1</version>
  <description>Custom message interfaces for offboard drone control</description>
  <maintainer email="l.jordan@student.tudelft.nl">Lauren Jordan</maintainer>
  <license>MIT</license>

  <buildtool_depend>ament_cmake</buildtool_depend>
  <build_depend>rosidl_default_generators</build_depend>
  <exec_depend>rosidl_default_runtime</exec_depend>

  <depend>builtin_interfaces</depend>
  <depend>std_msgs</depend>

  <member_of_group>rosidl_interface_packages</member_of_group>

  <export>
    <build_type>ament_cmake</build_type>
  </export>
</package>
```

6. Rebuild your package and resource 

```bash
colcon build 
cd ..
~/ros2_ws/install/setup.bash
```

7. Go into the package in which your ros2 system is defined. In this case it is /src/offboard_control_pkg. Go to the package.xml file and add the following build and executable dependencies.

```python 
...
 <build_depend>offboard_control_interfaces</build_depend>
...
 <exec_depend>offboard_control_interfaces</exec_depend>

``` 
8. Rebuild and source the `offboard_control_pkg` package
```bash
colcon build 
cd ..
~/ros2_ws/install/setup.bash
```
9. In the desired file where you would subscribe or publish to your custom topic, import them like so:
```python
from offboard_control_interfaces.msg import Drone1Info, Drone2Info, Drone3Info
...
#Example 
self.publisher_drone_1 = self.create_publisher(Drone1Info, 'drone1_info_topic', qos_profile)
```
You can now use them like regular topics.

10. Check your ros2 topic list by launching your desired files. Check the list using `ros2 topic list`. The custom messages should now display in the terminal.

```bash 
/drone1_info_topic
/drone2_info_topic
/drone3_info_topic
```
